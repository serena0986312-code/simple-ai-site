# Simple AI Website

Simple AI generator using Node.js, Express and the OpenAI API.

Setup

1. Copy `.env.example` to `.env` and set `OPENAI_API_KEY`.
2. Install dependencies:

```bash
npm install
```

3. Run the app:

```bash
npm start
```

Open http://localhost:3000 and enter a prompt, then click Generate.

Submission

- Push the repository to a public GitHub repo and provide the link. If you submit as a zip without a public Git link, you'll receive 0 per the assignment rules.
